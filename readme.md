## 📈 Model Evaluation

The models were evaluated using several metrics instead of relying only on accuracy:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

The **Decision Tree achieved around 89% accuracy** on the test dataset.

However, the results also showed that the positive class had relatively low recall. This was an important takeaway because in a credit-risk problem, simply getting a high accuracy score does not necessarily mean the model is performing well.

Looking at the **confusion matrix, precision, recall, and F1-score** gives a much better picture of how the model is actually performing.
